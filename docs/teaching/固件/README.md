# 固件获取与校验

本目录内的 CSV 是索引。随板发布方会提供适合所购板型的实际 IMG。初次体验优先用随板出厂应用，或索引中经该 SKU 验收的入门镜像。

使用 Python 3 校验。如果脚本和固件不在当前目录，用实际路径并加引号：

~~~text
py -3 "工具/校验固件.py" "固件文件的实际路径.img"
~~~

无需 Python 时，可用 Windows PowerShell 的 Get-FileHash -Algorithm SHA256，与索引的 SHA-256 逐字核对。哈希确认文件一致，板型和升级模式还应结合随版说明核对。

「含 UDISK」表示升级包内包含该数据/资源分区。保留数据升级时，应确认新版写入分区、格式和位置，先备份可迁移的配置。应用所需资源在 UDISK 时按发布方说明完整写入。完整写入可能清空该分区原有配网或授权记录。
