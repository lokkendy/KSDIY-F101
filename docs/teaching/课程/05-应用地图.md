# 已有应用怎么学

同一应用可能有早期实测版与较新的编译版。烧录时以索引中的具体版本为准。

| 案例 | 可学习的内容 | 验证边界 |
| --- | --- | --- |
| 木鱼、画板、时钟、钢琴等 | LVGL、触摸、定时、音频和持久化 | 有批量构建记录。SKU 实测按索引 |
| TF 卡 MP4 播放器 | 本地文件、硬解、旋转、HP/PA 音频 | S3 有独立镜像。S4 降频恢复曾出画出声，60 fps 同步未验收 |
| Action 6 无线监看 | BLE 授权、热点、图传、参数回读 | R16 实测图传，R17 实测规格和 EV。后续菜单版通过编译和主机回归。多机型扩展待完成 |
| Android 手机副屏 | 同一 Wi‑Fi 内的 H.264 镜像 | R1 小米 14 竖屏有画面，使用发送 APK。音频和回控见 Miracast |
| Miracast M10 | 系统投屏、LPCM 连续播放、UIBC 回控 | 小米 14 实测画面、声音及触控。其他机型和长期稳定性待扩测 |
| 拓竹屏、米家屏 | 公网授权、断电恢复、分页、异步 UI | 拓竹已测单台 P1P，多台真实设备待测。公网状态与 LAN 相机和文件应分别验收。米家覆盖按账号与设备核对 |
| 收音机、无线仪表台 | HLS、音频增益、Wi‑Fi/BLE 扫描 UI | 收音机 R5 有编译打包证据。无线仪表台的实机扫描待验证 |

用与手头设备匹配的版本演示。需要授权的案例使用自己的账号和设备，演示视频和课件使用脱敏日志。
