# 首次点亮与恢复

## 先确认 USB 设备在哪个阶段

| 阶段 | 去哪里看 | 能证明什么 |
| --- | --- | --- |
| FEL | OpenixSuit 设备列表 | Boot ROM 正在等待装载，可用于写入适配 IMG |
| RTOS 正常启动 | 屏幕、启动串口、适用应用的 ADB | 已进入应用，可继续检查触摸、网络和日志 |
| USB 副屏运行中 | 副屏 USB 接口和发送端 | 镜像使用自己的 USB 功能，调试用串口 |

## 操作卡

1. 写下板号、芯片、屏型号、Flash 类型与镜像版本。如果板已预烧录，先正常上电确认启动、触摸和亮度，记下出厂基线。可先做「实验／读启动日志」。
2. 取得随板镜像及 SHA-256，运行附带校验脚本。使用随板工具版本，按板卡说明进入 FEL，确认设备就绪，再选择对应 IMG。
3. 首次安装使用该镜像说明指定的模式。跨应用切换前考虑备份。已有配网、登录资料时，先检查升级包分区清单及 UDISK 是否会写入，再选择保留数据升级。
4. 等工具确认完成后正常重新上电。记录开机版本、分辨率、触摸是否于四角正常。使用 ADB 的应用可运行：

~~~text
adb devices -l
adb shell logcat
~~~

logcat 仅适用于提供该命令的镜像。遇到空列表，先区分数据线、FEL 残留、USB 功能差异和应用启动状态。串口日志可作为旁路。停在 DRAM 初始化时先复核镜像、硬件和启动参数。写入失败时记录最后成功阶段，再用同板型已验收镜像恢复。
