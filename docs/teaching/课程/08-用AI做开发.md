# 用 AI 和资料包一起开发

把「AI协作/F101项目上下文.md」、任务模板、相关课程和工程的少量相关源码放进 AI 工作区。指出真实 SDK 根目录，并说明 AI 能否读取。使用稳定版本创建可回滚的工作副本。

1. **先定位。** 提供板型、固件哈希、操作顺序和覆盖失败点的脱敏日志。让 AI 标出代码位置和证据。
2. **一次解决一个问题。** 指定验收门槛。优先复用现有 API，从可回滚的小改动开始。运行烧录命令前核对目标板、分区和恢复包。
3. **分开跑验证。** 先主机、再编译打包、再上板。让 AI 保留命令、SHA-256、实机数据和待测项。
4. **记录失败。** 当帧率没改善时，先确认测的是收到、解码、绘制还是翻页。保留成功与失败样本和回退办法。

## 可以直接复制的任务

> 这块板是 F101S3 / 4.3 英寸触摸屏。用资料包找到木鱼页面的触摸入口。先列出页面、模型和保存路径，再增加清零按钮。清零后界面应立即更新。先跑主机验证，输出变更文件和单应用构建命令。保留旧 IMG 供回退。

另一个练习是给 Wi‑Fi 页面增加「等待获取 IP」和「正在校时」两种反馈。用日志说明目前卡在哪一层。Wi‑Fi 密码、二维码令牌、访问码和 /data 完整备份保存在本机私有目录。
