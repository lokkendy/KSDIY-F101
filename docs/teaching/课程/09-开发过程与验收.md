# 开发过程与验收

| 阶段 | 已解决或验证的内容 | 对应学习点 |
| --- | --- | --- |
| 环境与启动 | WSL 原生构建、FEL、UART4/ADB、16 MB NOR 出包 | 配置区分、编译日志、镜像一致性 |
| 多应用与屏幕 | LVGL 多应用框架、横竖屏、MIPI 触摸、共享状态栏 | 布局、资源生命周期、旋转 |
| 联网与音频 | AIC8800D40L Wi‑Fi/BLE、开机播报、触摸提示音、PWM 息屏 | 网络分层、音频队列、电源事件 |
| 视频进阶 | Action 6 的内存、绿屏、花屏和帧率；Miracast 的配对、连续音频与回控 | 实际翻页、数据所有权、重连 |
| 可交付应用 | 拓竹云与局域网功能、米家登录保存、手机投屏 | 存储升级、状态回读、功能矩阵 |

## 每次交作业都写这六项

板型与屏幕、镜像与哈希、修改点、操作步骤、量化结果、待验证项。用真实设备反馈和板端日志交叉确认，并标出主机、板端和用户确认三种证据来源。

新增 SKU 时，用同一张表覆盖首次烧录、四角触摸、横竖屏、冷启动、配网、音量和恢复。跨屏尺寸记录实际耗时与内存。产品例程按实测边界展示，教学案例保留可复盘的已知故障。
