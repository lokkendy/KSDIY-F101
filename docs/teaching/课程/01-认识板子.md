# 认识板子

从点亮屏幕到独立开发应用。课程以 KSDIY F101S3 4.3 英寸开发板为例，全程记录芯片、屏幕、镜像版本和验证结果。

| 项目 | 教学基线 |
| --- | --- |
| 处理器与存储 | F101S3，16 MB PSRAM，16 MB SPI NOR |
| 显示与触控 | ST7102 MIPI 480×800，ST7123。横屏逻辑分辨率 800×480 |
| 调试与无线 | UART4，PD6 TX、PD7 RX，115200 8N1。选配 AIC8800D40L |
| 电源与音频 | 参考板使用 AXP2101，短按 PWRON 可息屏／唤醒。供电和音频端口看随板标注 |

准备数据线、Windows 电脑、随板说明、对应 IMG 和烧录工具。串口为可选项。连接串口前确认板上电平和端子定义，共地并交叉连接 TX/RX。上电和 FEL 操作以随板的板卡图为准。

| 学习顺序 | 完成后能展示 |
| --- | --- |
| 01–03 · 入门 | 上电、烧录、记录日志，修改一处 UI 后打包 |
| 04–05 · 项目 | 选一个本地或无线应用，写出输入、状态和验收项 |
| 06–09 · 进阶 | 排查 Wi‑Fi/TLS，定位图传瓶颈，让 AI 协助复现和修复 |

F101S4 的 32 MB PSRAM、供电与初始化需要独立验证。7 英寸和 10.1 英寸屏也要分别校验屏参、触摸坐标、刷新与缓冲开销。这些规格尚未列入本教学基线。
