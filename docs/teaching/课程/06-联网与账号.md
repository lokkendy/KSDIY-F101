# 联网、账号与保存

## 逐层排查 Wi‑Fi

从一个已经正常启动的镜像开始，依次记录 SDIO 初始化、驱动就绪、扫描、关联、DHCP、对时、TLS、业务登录。每层留下一个标志日志或错误码。连上热点但没 IP 时先检查 DHCP。TLS 因时钟失败时，先核对对时与 DNS，再定位认证。

## 完整断电验证保存

1. 使用自己的测试网络和授权账号，完成首次连接或登录。
2. 确认文件系统已挂载且保存成功，只记录存在性和校验结论。
3. 断开屏幕板供电和 USB，重新上电，观察自动联网、会话恢复和设备列表。
4. 单独测试升级保持。对照新旧分区地址与大小、镜像实际下载分区表，再记录升级前后的保留结果。一次冷启动通过只证明该次保存和加载生效。

| 现象 | 核对方式 |
| --- | --- |
| 公网有状态，首页显示离线 | 分开定义 Wi‑Fi、云会话、打印机状态，检查当前选中设备的 ID |
| 相机或存储没有数据 | 检查云端列表是否完成，是否匹配到同一台设备的局域网地址与认证 |
| 设备已执行，按钮还显示旧状态 | 分清下发、应答和回读。超时保留最后确认的值并给出提示 |

拓竹案例可用只读状态、相机和文件列表完成。公网控制权限、局域网开发者模式与打印机型号分别验收。
