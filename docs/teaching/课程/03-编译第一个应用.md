# 编译第一个应用

## 先跑通原版

使用 WSL2 的 Ubuntu 24.04 或发布方指定的已验证环境。将 SDK 解压到 Linux 文件系统，例如 ~/f101/sdk。SDK 依赖大小写文件名、软链接、玄铁交叉工具链和可执行的 32 位 x86 打包工具。在取得匹配的 SDK、获准使用的 KSDIY 项目和随版依赖说明后，运行：

~~~bash
cd ~/f101/sdk
test -L envsetup.sh
test -f lichee/rtos/projects/f101s3/ksdiy_f101s3/tools/build_all_apps.py
source envsetup.sh
lunch_rtos f101s3_ksdiy_f101s3
python3 "教学包实际路径/工具/编译木鱼.py" \
  --sdk ~/f101/sdk \
  --config "教学包实际路径/工具/wooden_fish.defconfig" \
  --out "$HOME/f101-out/wooden-fish-base"
~~~

把「教学包实际路径」换成解压后的 Linux 路径。--out 必须指向新目录。教学包附木鱼配置，仍需要随板提供的匹配 SDK 快照。脚本完成后检查 manifest.json、IMG 和 SHA-256。失败时先看 wooden_fish.build.log 或 wooden_fish.pack.log。当前开发树用通用批量脚本全清后出现过 SDMMC 重复定义，入门时使用匹配的发布基线与上面的单应用构建流程。

从工程根目录打开 src/app/apps/wooden_fish/Pages/Fish/Fish.c，在 ui_create_page_header 找到页面副标题，换成自己的短句。需要双语时一并补 src/app/Model/app_i18n.c 词条。用不同的 --out 再打包，确认新哈希与旧包不同，上板检查新文案、触摸敲击与计数。

附带的按键计数实验可先在电脑上完成。请保留原版 IMG 作为恢复版本。
