# F101 开发板教学包

先打开同目录的「开始学习.html」离线阅读，也可以用 PDF 打印讲义。教学基线是 KSDIY F101S3、16 MB PSRAM、16 MB SPI NOR、4.3 英寸 ST7102 MIPI 屏、ST7123 触摸。无线课程使用装有 AIC8800D40L 的板。请核对收到的实物版本。

- 「课程」是可编辑的 Markdown。
- 「实验」有可运行的 C、Python 样例，以及初学者读日志练习。
- 「AI协作」是可以直接交给 AI 的背景和任务模板。
- 「固件/固件索引.csv」列出归档镜像、SHA-256 与历史验证范围。基础 ZIP 提供课程和实验，SDK、烧录工具、固件和 APK 由随板渠道提供。收到 IMG 后可用「工具/校验固件.py」核对。
