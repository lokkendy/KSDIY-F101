# 读启动日志

下面的三段是重新编写的教学样例。方括号状态模拟实际设备的阶段，设备身份和网络信息均为占位数据。任务是在每个样例中指出最后成功的步骤，并写下下一项最小验证。

## A

~~~text
FEL device detected
Loading DRAM initialization executor
Timed out while waiting for DRAM initialization
~~~

## B

~~~text
[boot] UI started
[usb] ADB service init successful
[wifi] SDIO backend ready
[wifi] associated
[wifi] DHCP start
[app] waiting for IP
~~~

## C

~~~text
[boot] UI started
[wifi] DHCP ready: 192.0.2.10
[time] clock not synchronized
[tls] certificate verification failed
~~~

## 参考答案

- A 停在应用启动前。核对芯片、PSRAM、Flash 和镜像对应关系，用同板型已知可烧录包做对照。
- B 应用和网卡均已启动。关联只证明无线链路建立，下一步核查 DHCP 地址是否分配。
- C 已有 IP。先确认时间源与实际系统时间，再复验 TLS。保留证书校验，避免把绕过错误当成修复。
