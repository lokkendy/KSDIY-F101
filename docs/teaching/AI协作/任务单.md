# AI 协作任务单

复制下面的板卡资料和任务交给 AI，并补上方括号字段。

~~~text
任务 [例如：新增清零按钮]
当前工作区 [本机实际路径]
板型 [芯片 / 屏幕 / PSRAM / Flash / Wi-Fi]
当前镜像 [文件名、SHA-256、应用]
当前证据 [触发步骤、预期与实际、脱敏日志]
必须保留 [例如横竖屏、数据、原来的按键音和低延迟显示]
本轮范围 [先做小改动并构建，烧录留给我]
验收 [行为、次数、错误处理；如有性能目标写明统计定义]
交付 [变更位置、主机测试、构建命令、IMG 与待测项]
~~~

## 接力记录

| 字段 | 填写内容 |
| --- | --- |
| 起点 | 版本、板型、当前功能、已知问题 |
| 实际改变 | 文件路径、配置、接口和行为 |
| 证据 | 命令、日志文件／脱敏片段、镜像校验值、观察时间 |
| 结果 | 哪项通过、哪项复现、还缺哪种实机或账号 |
| 下一步 | 可以直接执行的一项验证 |
| 回滚 | 已验收的旧镜像、数据兼容情况、恢复方式 |
