# 给 AI 的 F101 项目上下文

本资料以 KSDIY F101S3 4.3 英寸开发板为基线。请先要求我填 SDK 实际路径、板号、芯片、存储介质、屏型号、无线模块和正在运行的 IMG。目录和硬件在课程里有参考，请结合当前工程的 defconfig、sys_config.fex、现有驱动与日志核对。

## 建议阅读顺序

1. 读「01-认识板子」和「03-编译第一个应用」，定位板卡与构建。
2. 读「04-从例程到新应用」和「05-应用地图」，找到应用入口。
3. 使用「任务单」把要求转成可验证的目标。联网读课程 06，视频读课程 07。
4. 主工程 app 在 lichee/rtos/projects/f101s3/ksdiy_f101s3，项目根目录下的 src/app 是共享 UI 和 Action 6。拓竹屏在 src/bambu_panel，米家屏在 src/mihome_panel。手机副屏与 Miracast 有各自分支来源，取所用版本对应的源码。

## 协作边界

- 先读现有 API 与版本配置。找不到模块、命令或编译日志时明确指出缺口。
- UI 只在其线程更新。网络、音频和解码各自保持任务与缓冲的所有权。
- 真实 H.264 指标分别记录网络包、完整 AU、解码、绘制和完成翻页。
- 账号授权、Wi‑Fi 密码、云 token、二维码、访问码和整份数据分区不要进入模型上下文。设备名称、IP、MAC、SN 也可替换成一致的占位符。
- 部署前核对镜像实际下载分区和回退包。编译通过、主机模拟、板端观测、用户确认要分别写。
