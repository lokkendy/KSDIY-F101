# 固件镜像

按屏幕分为 [4.3 英寸 ST7102](4.3-inch-st7102) 和 [10.1 英寸 JD9366](10.1-inch-jd9366)。[镜像索引](index.csv)列有文件名、配套板型、用途、大小及 SHA-256。

- 配套 APK 模式的无线副屏和 USB 副屏需要相应的发送端。Miracast 使用兼容手机的系统投屏。
- 标记“保留数据升级”的 IMG 用于匹配板型的已有系统。空板首次烧录或跨应用切换前，请先核对镜像的分区与资源。
- 如需核对历史实测范围，查看[教学资料的固件索引](../../docs/teaching/固件/固件索引.csv)。相同应用在不同屏幕和不同版本下的实测结果分别记录。
